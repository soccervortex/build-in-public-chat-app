# Building Dislite in public

A running log of building Dislite, a chat and community app, as a solo developer.

**The app: [dislite.xyz](https://dislite.xyz)**

## Why build in public

Most solo projects die quietly in a private repo. Sharing progress keeps momentum up and brings
in feedback earlier, before a feature is fully baked and harder to change.

## Recent progress

- Added bio display across profile views
- Added blocking, including blocking someone's ability to DM you
- Made friend profiles clickable from the friends list
- Ongoing work on real-time chat reliability

## Follow along

Updates land here and in the app itself. Feedback, bug reports, and feature ideas are always
welcome through [issues](../../issues).
